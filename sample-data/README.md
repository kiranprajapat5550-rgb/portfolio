# Sample Data

**Important: all records in this folder are fictional sample data created for demonstration and testing. They are not real customer, company, pharmacy, clinic, inventory, sales, or financial records.**

## `python-inventory-analytics-sample.csv`

This CSV is a small illustrative dataset for the inventory analytics script and unit-test workflow. Product names, SKUs, costs, stock quantities, lead times, safety-stock values, and monthly quantities are synthetic examples. Do not use these values for purchasing, replenishment, financial reporting, or operational decisions.

The first row contains the CSV column headers. Keep the CSV header unchanged when using it with the sample analytics script. Replace the sample rows with data you are authorized to use before applying the script to a real workflow, and validate outputs before making decisions.
